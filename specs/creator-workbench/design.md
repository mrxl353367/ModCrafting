# 首轮配方闭环

用户于 2026-10-15 选择“合成配方：拖放编辑→保存→游戏验证”，本设计仅覆盖 R1/R2 的首轮交付。

- 将旧 recipe-utils 的纯格式/校验代码移入 Core，旧路径 re-export，保留旧调用行为；网格换位纯函数同样共享。
- Core 增加配方工作区操作：catalog/list/read/save。Web 与一个领域 MCP 工具共用它，不增加模型或 Agent Loop。
- 工程文件是事实来源。读回包含 SHA256；新建必须传 null，覆盖必须传匹配的旧 SHA。保存前展示变更；遇到外部改动拒绝保存并保留草稿。
- 路径只接受 Fabric 工程下 data/<namespace>/recipe/<name>.json，拒绝路径穿越/链接。未知配方只读；支持类型保留原有额外元数据。
- Web 提供配方列表、可搜索材料、九宫格或单材料编辑、产物和数量、原文件/待写入 JSON 对比、保存/重新加载。复用现有 React、CSS 与 MC 网格语义，无新增依赖。
- 交付以受控新示例工程验收，保留历史工程/世界；真实 MCP 读回 Web 保存结果，再构建、在专用测试世界实际合成并检查奖励/消耗。截图只作界面证据。

首轮不包含复杂自定义 serializer 的可视化编辑、任意 Java 反向解析、资源图标自动下载、实时修改正在运行游戏的配方或通用编辑器框架。
