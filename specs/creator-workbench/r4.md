# R4 MC 界面创作实施与验收

复用旧 GuiLayoutElement 的稳定 ID、类型、位置/尺寸、颜色/透明度/阴影语义，以及 8px 网格和 4px 对齐阈值。旧 iframe 使用 AI HTML、脚本注入及未限制来源的 postMessage，不迁入新 Web；采用已有 React 渲染结构化布局，不接收任意 HTML/JavaScript。

首轮支持 custom-screen、option-list、hud-overlay。组件为标签、面板、按钮、开关、滑块及展示槽位；HUD 不包含交互控件。按钮仅支持递增指定数值控件、恢复默认和关闭界面；开关/滑块本地持久化，标签可绑定对应值或玩家生命/饥饿。展示槽位不执行容器交换/服务端同步。原生控件沿用 Minecraft 皮肤；标签/面板支持颜色、透明度、文字阴影。

浏览器包含编辑/交互预览、拖动/调整尺寸、网格/边缘对齐、属性、GUI 缩放/窗口比例及布局锚点。交互预览只模拟；保存前检查生成文件，确认写回后 Agent 读取同一声明与版本。生成每布局独立客户端入口、原生 Screen/HUD/按键和配置文件；复用 R3 文件哈希、冲突、备份和回滚模式，未知或外改 Java 只读。
