# 浏览器工作台

可选浏览器工作台与 MCP 共用一个本地 Core 后端。启用 MCP 配置中的 `--web` 后，`modcrafting_open_workbench` 返回本地链接；工具会尝试打开浏览器，打开失败时仍返回可复制链接。单独执行 `pnpm start` 会以 `--web-only` 启动浏览器服务。

链接包含本机 Token 和后端标识，不应公开分享。页面关闭不会停止任务。工作台只查询当前后端与选定 session 的状态；切换 session 时取消旧请求、停止旧轮询并丢弃迟到响应。

## 布局和导航

顶部显示任务、工程、session 和运行状态。左侧侧栏提供概览、内容、配方、界面、构建、游戏、测试和报告；主区一次只挂载一个模块，窄窗口折叠导航。日志位于可收起诊断区。

Agent 可通过 `modcrafting_session` 更新当前阶段和推荐模块。启用“跟随 Agent”时工作台按推荐模块导航；用户手动切页后暂停自动导航，重新启用跟随后恢复。用户始终可以自行选择模块。

## 草稿和保存

内容、配方和界面草稿按 session 与工程分别保留，不因切换模块自动保存。恢复前 Core 会重新核对工程版本；保存操作继续使用 `expectedRevision` 和预览 revision，冲突时保留草稿并要求重新读取。

游戏配置位于游戏模块。配置默认只作用于当前 session；只有用户显式选择保存为工程默认才写入工程。游戏运行期间修改标记为“下次启动生效”，不覆盖正在运行的设置。

## 安全边界

浏览器只向当前本机后端发送工作台操作。静态文件与 API 共用随机 Token；报告和截图只能读取当前 session 拥有的产物路径。前端不读取任意本地路径，也不直接连接 Observer。

更完整的会话、任务和权限契约见 [Core 接口](core-contracts.md)。
